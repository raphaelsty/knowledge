    Zotero

    Save links from any browser or phone. Items land in your Zotero library with whatever it picks up — tags, notes, the PDF — and we sync from there into your search index. Free and open-source. Create an API key at zotero.org/settings/keys/new and paste it below. We store it encrypted and never read it back.

    Setup
    • Desktop: install the Zotero app and the browser connector. Click the toolbar icon on any page to save it.
    • Mobile: the iOS app or Android app. Share any URL to Zotero.
    • Mint an API key at zotero.org/settings/keys/new with Allow library access on, then paste it below.
    • Your saved items live at zotero.org/mylibrary.

        Politique de confidentialité

        Le site applique le RGPD. Nous collectons le strict minimum nécessaire pour faire fonctionner la recherche et améliorer le service.

        Ce qui est collecté

        • Compte — adresse email, mot de passe haché, slug public. Sert à l'authentification et à la récupération de compte.
        • Sources liées — identifiants publics (GitHub, HuggingFace, X/Twitter, Zotero, Reddit, Stack Overflow) que vous saisissez vous-même. Les secrets éventuels (mot de passe HN, clé API Zotero) sont chiffrés au repos.
        • Mesure d'audience anonyme — pages vues, requêtes de recherche, clics sur les résultats, filtres utilisés. Pas d'adresse IP stockée, pas de cookie tiers, pas d'empreinte navigateur. Conforme à l'exemption CNIL de mesure d'audience (délibération n° 2020-091), donc aucun bandeau de consentement n'est requis.

        Ce qui n'est pas collecté

        • Pas de cookie publicitaire ni de pixel tiers.
        • Pas d'adresse IP conservée.
        • Pas de revente de données.
        • Pas d'empreinte navigateur (user-agent, OS, taille d'écran, etc.).

        Vos droits

        Vous pouvez à tout moment accéder à vos données, les rectifier, demander leur effacement, ou exporter une copie. Écrivez à raphael.sourty@gmail.com. Vous pouvez aussi saisir directement la CNIL en cas de litige.

        Opt-out

        Vous pouvez désactiver la mesure d'audience pour ce navigateur — ouvrez la console et exécutez localStorage.setItem('_analytics_optout','1'). Le réglage est local à votre navigateur.
